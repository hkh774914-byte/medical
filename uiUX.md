UI/UX DESIGN SPECIFICATION
K.K. Bone & Joint Care
Design Platform

Google Stitch MCP via Antigravity

Design Type

Premium Medical / Orthopedic Clinic Website

Primary Design Goal

Create a visually premium, trustworthy, modern and patient-friendly website for K.K. Bone & Joint Care, Rahon.

The design must feel like a genuine established healthcare brand, not a generic medical website template.

The interface should communicate:

Trust → Expertise → Care → Clarity → Action

The website should make a visitor feel comfortable contacting the clinic within the first few seconds.

1. DESIGN PHILOSOPHY

The visual language should combine:

Medical professionalism
Modern healthcare aesthetics
Human warmth
Premium editorial design
Strong local identity
Minimal visual clutter

The website should NOT feel:

Cold
Corporate
Overly clinical
Like a hospital administration portal
Like a generic Bootstrap template
Like a stock AI-generated website
Over-animated
Filled with unnecessary gradients

The design should prioritize trust and readability over visual gimmicks.

66. STITCH GENERATION INSTRUCTIONS

When generating the design through Google Stitch MCP, follow these instructions:

Instruction 1

Generate the design as a premium healthcare brand website, not a generic medical template.

Instruction 2

Prioritize mobile-first usability, while maintaining a sophisticated desktop composition.

Instruction 3

Use the defined design system consistently across all sections.

Instruction 4

Use large typography and generous whitespace to create a premium visual hierarchy.

Instruction 5

Use realistic medical photography placeholders where actual clinic photography is unavailable.

Instruction 6

Keep all business-specific information that has not been verified as clearly replaceable placeholder content.

Instruction 7

Do not invent doctor credentials, patient numbers, ratings, reviews, awards or medical claims.

Instruction 8

Make appointment/contact CTAs visually prominent without making the website feel like a sales landing page.

Instruction 9

Design all important interaction states.

Instruction 10

Ensure every component can realistically be implemented in HTML, CSS and JavaScript.

67. STITCH MASTER DESIGN PROMPT

Use the following as the primary design-generation instruction inside Antigravity/Stitch:

Design a premium, modern and trustworthy healthcare website for K.K. Bone & Joint Care, a bone and joint care clinic located in Rahon, Punjab, India.

Create a sophisticated contemporary medical aesthetic using deep healthcare blue/teal, warm off-white backgrounds, white surfaces, dark charcoal typography and subtle healthcare-green accents.

Use Manrope or a similar modern sans-serif typeface, large editorial headings, generous whitespace, soft rounded corners, subtle borders and restrained shadows.

The visual experience should communicate professionalism, expertise, warmth and trust without feeling like a generic hospital template.

Build the homepage with:

Sticky navigation
Premium hero section with clinic speciality, Rahon location, strong headline, supporting copy, Book Appointment CTA and Call CTA
Quick clinic information strip
About clinic section
Bone and joint services section
Conditions/problems section
Doctor profile section
Why Choose Us section
Patient journey section
Testimonials
Clinic gallery
FAQ accordion
Contact and appointment section
Location/map area
Premium footer

Use strong visual hierarchy and conversion-focused CTA placement.

Design desktop, tablet and mobile responsive experiences.

On mobile, include a fixed bottom CTA bar containing Call, WhatsApp and Book Appointment.

Use professional medical photography placeholders and avoid graphic medical imagery.

Create reusable components for buttons, cards, forms, navigation, FAQ, gallery and appointment interactions.

Include hover, focus, active, loading, error and success states for interactive components.

Do not invent doctor qualifications, experience, patient statistics, testimonials, ratings, awards, certifications or medical outcomes. Use clearly marked placeholders for information that has not yet been provided.

The final result should feel like a professionally designed private orthopedic/bone-and-joint clinic website that could be presented directly to a clinic owner as a high-end website proposal.

Avoid excessive gradients, excessive glassmorphism, excessive animations, generic stock-template layouts, oversized decorative medical icons and unnecessary visual complexity.

Prioritize trust, readability, accessibility, mobile usability and appointment conversion.
